## 入力
* 入力モードへの移行: `i`、`a`、`A`、`o`、`R`
    * `i`: カーソル位置から挿入
    * `a`: カーソルの次の位置から挿入
    * `A`: 行末から挿入
    * `o`: 現在の行の下に改行して挿入モード
    * `R`: 上書きモード

## コピー・貼り付け
* `yy` 行コピー
    * `3yy` 3行コピー
* `10G` で10行目に移動してから `yy`（`10yy` はカーソル行から10行のコピーになる点に注意）
* `p` 貼り付け（カーソル行の下）
* `P` 貼り付け（カーソル行の上）

## やり直し
* `u` アンドゥ
* `Ctrl-r` リドゥ

## 削除
* `dd` 行削除（切り取りも兼ねている）
* `3dd` 3行削除
* `x` 1文字削除
* `D` カーソル位置から行末まで削除
* `C` カーソル位置から行末まで削除して挿入モード

## 検索
* `/` 下方向へ検索
* `?` 上方向へ検索
* `n` 次の候補へ
* `N` 前の候補へ

## 置換
* `:%s/検索文字列/置換文字列/g` でファイル全体を置換する。
* スラッシュを含む文字列を扱う場合はバックスラッシュでエスケープする。
    * 例）複数行にわたる処理をまとめてコメントアウトする（開始行と終了行をそれぞれ置換する）
    ```
    :%s/Mail::send/\/\* Mail::send
    :%s/});/});*\//
    ```
    * (IMO) この方法は対象がファイル全体に及ぶため、意図しない箇所まで置換してしまいやすい。後述のビジュアルブロックによるコメントアウトや、範囲を指定した置換（`:10,20s/.../.../`）の方が安全。

## 移動
* 1文字単位
    * 右: `l` / 左: `h` / 下: `j` / 上: `k`
* 行内
    * 行頭: `0`（インデントを除いた行頭は `^`）
    * 行末: `$`
* 単語移動
    * `w`、`W`: 次の単語の先頭に前進
    * `b`、`B`: 現在の単語もしくは前の単語の先頭に後退
    * `e`、`E`: 単語の末尾まで前進
    * 大文字の方は、ドット（`.`）やコロン（`:`）のような記号もひと続きの単語とみなして移動する。
* 段落移動: `{`、`}`
* ページ移動: `Ctrl-u`、`Ctrl-d`、`Ctrl-b`、`Ctrl-f`
    * `zz`: 現在のカーソル位置が中央になるように画面をスクロール
    * `zt`: 現在のカーソル位置が一番上になるように画面をスクロール
* ファイルの先頭: `gg` / ファイルの末尾: `G`
* 行番号を指定して移動: `<行番号>G`
* 行内の文字検索
    * `f` + 1文字: カーソルがある行の中で、入力した文字に該当する場所へ前方移動
    * `F` + 1文字: 同じく後方移動
    * `;`: 直前の `f` / `F` の移動を繰り返す
    * `,`: 逆方向に繰り返す

## テキストオブジェクト
* 削除
    * `diw`: カーソル上の単語を削除
    * `di"`: ダブルクォーテーションの内部を削除
    * `dit`: HTMLタグの内部を削除
* 削除して挿入モード
    * `ciw` / `ci"` / `cit`
* コピー
    * `yiw` / `yi"` / `yit`
* 選択
    * `viw` / `vi"` / `vit`

## インデント
* `>>`: インデントを追加
* `<<`: インデントを削除

## その他
* `.`: 直前のコマンドを繰り返す
* 複数行の一括編集（ビジュアルブロックモード）
    * 複数行を同時に編集・削除したい場合は、ビジュアルブロックモードを使う。
    1. 対象の先頭行で `Ctrl-v` を押す
    2. `j` を押して対象の最終行までカーソルを移動させる
    3. `Shift-i` を押して挿入モードにする
    4. 挿入したい文字（コメントアウトなら `#`）を入力する
    5. `Esc` を押すと、選択していた全ての行に反映される
    * 行頭の文字をまとめて削除したい場合は、`Ctrl-v` で範囲を選択した後に `x` を押す（コメントアウトの解除に使える）。
