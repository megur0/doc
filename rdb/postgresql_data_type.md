## データ型（PostgreSQL）

### PostgreSQLのtextはU+0000をエラーにする

U+0000を弾く。UTF-8に違反はしていないが、PostgreSQLのテキスト型はU+0000を禁止しているため実行時エラーになってしまう。

- (参考) [Handling unicode sequences in PostgreSQL - Stack Overflow](https://stackoverflow.com/questions/31671634/handling-unicode-sequences-in-postgresql)

`invalid byte sequence for encoding "UTF8" 0x00` のようなエラーが出る。


### データ型

- (参考) [PostgreSQLのデータ型まとめ - Zenn](https://zenn.dev/uta_mory/scraps/5e0b03c9b3478b)
- (参考) [PostgreSQL: データ型](https://www.postgresql.jp/document/14/html/datatype.html)
- serial型ではなくIDENTITYを使う。serial型には、スキーマ、依存関係、パーミッション管理を不必要に煩雑にする挙動があるため(?)。
- varchar(n)とtextのパフォーマンスの違いはない。違いは長さ制限があるかどうか。なお `n` はバイト数ではなく文字数。
    - (参考) [varcharとtextの違い(PostgreSQL)](https://postgresweb.com/post-5713)
- 日付
    - TIMESTAMP型: Date型 + Time型 = TIMESTAMP型
    - Date型
    - Time型
- real、double precision（浮動小数点型）
    - 小数点以下の桁数が可変長の実数。2進数で記憶するため、保存される値には誤差が出る。
        - (参考) [浮動小数点型の誤差について](https://shiro-secret-base.com/?p=924)
    - 金額といった正確性を必要とする場合はnumeric型を使う。
    - (IMO) 保存した値がずれてしまうのであれば、浮動小数点を積極的に使うケースはほぼないのではないかと思う。
- numeric: 誤差なし。


### uuid

- uuid型
    - (参考) [PostgreSQL: UUID型](https://www.postgresql.jp/document/14/html/datatype-uuid.html)
- 自動生成
    - `uuid-ossp` という拡張を生成しておく。
    - (参考) [PostgreSQLでのUUID自動生成](https://salumarine.com/how-to-use-autogenerated-uuid-primary-keys-on-postgresql/)
    - (参考) [Postgres UUIDについて](https://arctype.com/blog/postgres-uuid/)
- SQL
    - 以下のSELECTでは、キャストしてもしなくても実行結果は一応同じだった（おそらく暗黙的にuuidとしてキャストされている(?)）。

        ```sql
        SELECT * FROM users WHERE id = '11111111-1111-1111-1111-111111111111'::uuid
        SELECT * FROM users WHERE id = '11111111-1111-1111-1111-111111111111'
        ```

    - ただし、下記の場合は明示的にキャストしないとエラーとなった。

        - OK

            ```sql
            SELECT * FROM rooms WHERE id = ANY(array['11111111-1111-1111-1111-111111111111'::uuid, '22222222-2222-2222-2222-222222222222'::uuid, '33333333-3333-3333-3333-333333333333'::uuid])
            ```

        - NG（`operator does not exist: uuid = text`）

            ```sql
            SELECT * FROM rooms WHERE id = ANY(array['11111111-1111-1111-1111-111111111111', '22222222-2222-2222-2222-222222222222', '33333333-3333-3333-3333-333333333333'])
            ```
